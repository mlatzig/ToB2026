only `Lemur-Simsilica-BSD-3-Clause.txt` is extracted from the source files. `ReleaseBuildTest` pins the
SHA-256 of each; the release build ships the files of `Platform.LICENCE_TEXTS` in the packages'
`licenses/` folder (this manifest is not shipped).
